COMO FOI FEITO
O modelo físico define a implementação no MySQL 8 (motor InnoDB,
codificação utf8mb4): tipos de dados, tamanhos, restrições e índices.
Principais decisões:
  - PK do tipo INT AUTO_INCREMENT (livro_autor: PK composta).
  - NOT NULL nos campos obrigatórios (RN04: datas do empréstimo).
  - UNIQUE em isbn, cod_patrimonio, cpf, email e login (RNF06).
  - ENUM nos campos de situação (status do exemplar - RF13).
  - CHECK: devolução prevista não pode ser antes da retirada.
  - Índices em título, nome e status para consultas rápidas (RNF04).
  - FK com ON DELETE RESTRICT: não apaga livro/leitor com histórico (RN09).

Para gerar o diagrama EER no MySQL Workbench a partir do script:
  File > Import > Reverse Engineer MySQL Create Script
  e selecione 05_Scripts_SQL/00_script_completo.sql.
